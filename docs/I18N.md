# Bahasa aplikasi (Indonesia / English)

Pengguna memilih bahasa di halaman login. Pilihan disimpan di browser (`localStorage`, kunci `dod.lang`), bawaannya bahasa Indonesia.

## Cara kerja

- `src/i18n/index.ts`: `tr('Teks Indonesia', arg0, arg1)` mengembalikan teks dalam bahasa aktif; `{0}`, `{1}` diisi argumen. `LOCALE` dipakai untuk format angka dan tanggal.
- `src/i18n/en.ts`: kamus Inggris, kuncinya teks sumber di kode.
- `src/i18n/id.ts`: padanan Indonesia untuk teks sumber yang masih memuat istilah Inggris (Report → Laporan, Dashboard → Dasbor). Teks tanpa entri tampil seperti tertulis di kode.
- Ganti bahasa memuat ulang halaman, sehingga `tr()` juga aman dipakai untuk konstanta di tingkat modul.

## Menambah teks

Bungkus teks baru dengan `tr()`, tulis dalam bahasa Indonesia baku, dan tambahkan entrinya di `en.ts`. Bila memakai istilah Inggris, tambahkan juga di `id.ts`. `tests/i18n.test.ts` memeriksa placeholder dan teks yang jelas berbahasa Indonesia tetapi belum punya entri.

## Istilah yang sengaja tidak diterjemahkan

Nama produk dan singkatan teknis: Daily Operation Discovery, DOD, Excel, HTML, PDF, CSV, API, SQL, PostgreSQL, AI, KPI, serta nama sistem dan variabel konfigurasi.

## Teks dari server

Server tetap menulis bahasa Indonesia. Teks tetap (pesan error lewat `ApiError`, katalog Hak Akses Menu, keterangan field, notice Data Profil) diterjemahkan frontend lewat kamus yang sama. Yang tetap berbahasa Indonesia:

- pesan server yang memuat nilai dinamis, misalnya nama kolom;
- data: nama kebun, kategori, label dataset, kode seperti `EVALUASI PEREMAJAAN`, nama sheet template Excel.
