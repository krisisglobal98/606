# DOD Minimal – Tech Stack

Every version is pinned exactly in `package.json` / `server/package.json` and locked in the matching `package-lock.json`.

## Runtime

| Technology | Version | Purpose |
|---|---|---|
| Node.js | 24 LTS (`.nvmrc`; `engines` ≥ 24.0.0) | Tooling and API runtime. The API runs TypeScript directly (type stripping): no build step for `server/` |
| PostgreSQL | ≥ 14 (local server: 18) | Application database and the optional databases on the same server |

## Frontend (`package.json`)

| Technology | Version | Purpose |
|---|---|---|
| React / React DOM | 19.3.0 | UI |
| TypeScript | 6.0.3 | Static typing (strict). Not 7.x yet: `typescript-eslint` 8.71 supports `< 6.1` |
| Vite + `@vitejs/plugin-react` | 8.3.2 / 6.1.1 | Dev server (port 5180), production build, preview (port 8100) |
| React Router | 8.4.0 | `createBrowserRouter`, protected and menu-guarded routes, lazy pages |
| Zustand | 5.0.15 | Shared state: `authStore`, `analysisStore`, `uiStore`, `reportStore`, `gridPrefsStore`, … |
| Apache ECharts | 6.1.0 | Charts, imported from `echarts/core` (tree-shaken, lazy-loaded); no wrapper library |
| Zod | 4.6.5 | API contracts; runtime validation of responses; form validation |
| lucide-react | 1.52.0 | Icons |
| `@fontsource-variable/plus-jakarta-sans` | 5.3.0 | Self-hosted typeface (no Google Fonts request) |
| CSS custom properties + CSS Modules | – | Design tokens in `src/styles/tokens.css` (light/dark, density); shared primitives in `global.css`. No CSS framework or UI kit |

Development: ESLint 10.12.0 + typescript-eslint 8.71.0 + react-hooks 7.1.1 + react-refresh 0.5.7; Node's test runner for `tests/` and `server/test/`.

## Backend (`server/package.json`)

| Technology | Version | Purpose |
|---|---|---|
| Fastify | 5.12.5 | HTTP API |
| pino | 10.4.0 | Structured JSON logs with redaction of secrets and auth headers |
| pg (node-postgres) | 8.23.1 | Application database and PostgreSQL sources: pools, statement timeouts, cancellation |
| `@clickhouse/client` | 1.24.0 | ClickHouse sources (HTTP) |
| mysql2 / mongodb / redis | 3.24.5 / 7.7.0 / 6.3.0 | MySQL, MongoDB and Redis sources (connect, test, browse) |
| nodemailer | 10.1.0 | Report e-mail through the configured SMTP server |
| Zod | 4.6.5 | Configuration, request and semantic-model validation |
| TypeScript | 6.0.3 | Typecheck only (`erasableSyntaxOnly`) |

No ORM: queries are explicit, and the analytics SQL is generated by DOD's own builder (`server/src/analytics/sqlBuilder.ts`). The `QueryEngine` interface (`server/src/dw/queryEngine.ts`) keeps the engine behind one contract.

## Delivery

| Technology | Purpose |
|---|---|
| IIS 10 + URL Rewrite 2.1 + ARR 3, NSSM | Windows Server deployment (`deploy/windows/`, `public/web.config`) |

## Not used

No map library (the GIS module was removed), no service worker, no mock API, no data-fetching library (`src/hooks/useResource.ts` covers cancellation), no CSS framework or UI kit, no PDF library (reports print to PDF from the browser), no messaging SDK (WhatsApp/Telegram are not implemented).
